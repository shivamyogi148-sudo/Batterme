BetterMe v0.8 — Phase 8 / Final Prototype Layer

Added:
- Data & Privacy center
- Explicit AI-photo consent gate
- Optional analytics consent
- Local data deletion flow
- App settings (haptics, sound, private mode)
- Release Readiness checklist
- Better Self generation is blocked until explicit photo consent is enabled
- Final prototype navigation for settings/privacy/release readiness

Production blockers before Play Store:
1. Real encrypted persistence.
2. Real authentication and backend authorization.
3. Secure AI backend with server-side provider key.
4. Native notification scheduling + OS permission handling.
5. Native biometric authentication.
6. Backend account/data deletion and export.
7. Automated tests, device testing, accessibility and security audit.
8. Privacy policy/terms and Play Console declarations.
9. Signed release AAB and Play Store listing assets.

This is a final-prototype layer, not a claim that those production services are already live.
